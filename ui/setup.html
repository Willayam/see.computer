Set up see.computer

macOS asks for each of these separately. Click Allow, answer the dialog, and the row ticks off by itself.

  1. 1
    Microphone
    Hears you while you hold the key.
    Allowed
  2. 2
    Input Monitoring
    Notices when you hold Fn (Globe). It reads no other keys.
    Allowed
  3. 3
    Accessibility
    Types your words where the cursor is.
    Allowed
  4. 4
    Screen Recording · optional
    Only for screenshots and clips. Dictation works without it.
    Allowed
  5. 5
    Try it
    Click into any text field, hold Fn (Globe), say something, and let go.
    Waiting

If a row stays unticked after you allow it, quit see.computer from the menu bar and open it again. macOS applies some of these only on relaunch.
